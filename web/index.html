Review Package Explorer

GITLAB CI REVIEW, MADE CLEAR

Turn CI results into a clear review plan.

TO BUILD A FIRE analyzes a GitLab merge request (MR) and creates a Review Package: a report showing what changed, which checks ran, and what still needs human review. This page displays that report; it does not connect to GitLab directly.

Evidence text from agents is shown in its original language.

THE PROCESS

How it works

  1. 1

    GitLab CI checks the merge request

    The pipeline gathers the changed files and the results of configured checks.

  2. 2

    The pipeline creates a report

    It creates a file named review-package.json. You do not write this file yourself.

  3. 3

    Open the report here

    For this demo, download the artifact from the attention-router-mr-snapshot job, then choose it below. The file stays on your device.
